:::warning

**Important — back up before you edit:** Always keep a copy before changing a process. You can back it up in either of these ways:

**• Clone the process** — makes a copy you can keep as the backup.

**• Download (Export) the process** to a file — you can Import that file again later to restore it.

:::

**1.** Open **Home → Process Management** and find the process. Make a backup first (Clone, or Export to a file) using the icons <img src="/media/user-guide/image9.webp" class="icon" alt="Clone and Export icons" />.

![Screenshot](/media/user-guide/image10.webp)

**2.** To restore later, use **Import** and choose the process file you saved.

![Screenshot](/media/user-guide/image11.webp)

![Screenshot](/media/user-guide/image12.webp)

*Import — choosing a process file to load.*

*Click Submit to successfully import the selected process.*

![Screenshot](/media/user-guide/image13.webp)

**3.** Open the process, go to the tab you want to change, make your change, then click **Save** and save the process.
